# 隋前至唐末五代十国：水脉与天下

版本 v0.2，2026-11-02。新增独立长剧本，保留明初十五年剧本。本文的分章和预算属于开发基线；历史转折不是强制重演的玩家失败条件。

## 时段与游玩形式

暂以 550 年初至 979 年末覆盖隋前南北分立、隋、唐及五代十国，结束边界为 980 年初，共 430 个模型年、15480 旬。“隋前”选取六世纪中叶作为可操作开局；更早形成的河渠作为继承资产与史实卡呈现，不宣称重现全部先秦至南北朝历史。

支持六章独立游玩及连续传承。独立章使用经过考据的起始快照；连续模式使用玩家真实结果，不能切章时用史实快照覆盖。每章目标 12—20 次关键决定、20—40 分钟，整部战役适合分次游玩；这些是试玩目标。平稳年月自动逐旬推演，出现有行动空间的变化才暂停，界面显示多年摘要与地区趋势。

|章|观察窗口（结束不含）|核心取舍|场景目标|
|---|---|---|---|
|一：分流之世|550—581|既有区域水道、跨政权转运、地方农时与修复|辨认分裂格局下可行的局部连接，不强求全国联网|
|二：贯通南北|581—618|以洛阳相关供给为背景的干线整合；征役、营建、军事共同占用|选择分段疏浚、新建、规格与工期，避免短期集中征发|
|三：旧渠新用|618—755|继承与复修、江淮供给及向关中转输|维护、换装与备用路径的长期价值|
|四：兵乱与财赋|755—820|运输中断、地区控制变化、军需挤占及财政恢复|保住关键民生线路，适应新的资源出资方|
|五：河道与地方|820—907|中央/地方执行能力变化、地方利益与网络依赖|在主干、地方支线、风险储备之间取舍|
|六：多国共水|907—980|多个政权、通行权、不同出资方、跨境水道与区域繁荣|在反复变化的政治边界下保留有用的水路遗产|

上述时间是内容观察窗口。分裂、统一、战争等转换须检查世界条件；若玩家影响使条件不成立，章节仍可进入下一观察阶段，但保留实际政权格局，以架空分支替代不再适用的历史事件。979 年作为五代十国相关历史终局的观察参考，游戏不会在该年强制所有政权按史实消失。

## 地图与知识限制

首批覆盖关中、洛阳及黄河转运、汴/淮走廊、江淮、江南与北方通道。采用约 16—24 个区域、30—45 条主要运输边的复杂度预算；扩展需有明确的决策收益。

优先研究既有邗沟/山阳渎走廊、广通渠、通济渠、永济渠、江南水道及唐代转输节点。这里只定义研究范围，不把各时期同名河道画成一条永恒不变的线。未有充分证据的河段只作候选走廊或停用，不填造价与精确容量。

明代南旺分水、元代会通/通惠工程及后世闸制不能直接移植到此剧本。水工技术通过 capabilityIds 与证据控制；首版以浅水小船、堰埭/转运、疏浚和有证据的蓄泄设施表达技术差异，具体结构须逐时期核验。

史实起点：隋代通济渠、永济渠等工程与大规模征发可从[《隋书》卷三](https://zh.wikisource.org/wiki/隋書/卷03)及[既有事件与来源](../../grand-canal-atlas/wiki/06-events.md)核对；运河分期建设和帝国运输背景见[UNESCO 大运河说明](https://whc.unesco.org/en/list/1443/)。唐代与五代各地方事件需由历史内容 Agent 新增原始来源和学术核查后入库，本文不把待研究题材当作已证实的事件脚本。

## 继承与政治事件

使用 WorldTransitionPlan：明确 predecessor/successor IDs、地区控制映射、资产归属映射、承诺承认/拒付、通行权变动及依据。没有映射的财产进入显式争议托管，不能消失或自动平分。转换是原子事件，失败回滚；事件保留原主体 ID，继任者不会篡改历史责任。

未来拨款可被新政权拒绝，已花资源与劳动不能追回；未花托管额度按归属规则转移一次。对在途货物按所在节点和所有权处理，不能在边界变化时瞬移或复制。维修与保全责任绑定物理设施，责任承担者可变，责任量仍在。

若选择高历史约束模式，外部大势节点可按预告日期进入，但资源与工程结果继续按模拟计算；默认连续模式采用条件转换。两种模式在开局明确区分，不能中途暗改。

## 长期经济与结束

人口、农业与商业增长设地区承载上限、递减收益和灾后恢复；使用同一规则逐旬计算，不以多年一次乘数替代。参数按制度阶段版本化，切换过程有事件依据，不能用调参悄悄清空负担。

各章保留天下与遗产两份评价。完整战役在 980 年初结束；个别政权覆亡不是通用结束条件。持续无人居住/无人维护且无任何有效水网的区域可退出模拟，但全国级提前终止须有独立条件及预警，不能沿用明初单政权失败阈值。
